# Melkam Demelash Wondimeneh - Portfolio Website

A modern, responsive portfolio website showcasing the skills, projects, and professional profile of Melkam Demelash Wondimeneh, a Full Stack Developer and Computer Science student.

## 🚀 Features

- **Modern Dark Theme Design** - Professional appearance with carefully chosen color palette
- **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- **Smooth Animations** - Interactive elements and scroll animations
- **Single Page Application** - All sections in one HTML file with smooth navigation
- **Contact Form** - Functional contact form with email integration
- **Project Showcase** - Featured projects with technology stacks
- **Skills Display** - Animated skill bars showing proficiency levels
- **Social Links** - Integrated social media and professional profiles

## 📁 Project Structure

```
portfolio-website/
│
├── index.html              # Main HTML file with all sections
├── css/
│   └── style.css           # Complete stylesheet with dark theme
├── js/
│   └── script.js           # Interactive JavaScript functionality
├── images/                 # Profile and project images (add your images here)
├── assets/                 # Resume PDF and other assets
└── README.md               # This file
```

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Add your images** to the `images/` folder:
   - `profile.jpg` - Your professional profile photo
   - `project1.png` - Project screenshots
3. **Add your resume** to the `assets/` folder:
   - `resume.pdf` - Your professional resume
4. **Open `index.html`** in your web browser

## ⚙️ Customization

### Personal Information
Update the following in `index.html`:
- Name and title in the hero section
- Contact information
- Social media links
- Project details

### Styling
Modify `css/style.css` to:
- Change colors (update CSS variables)
- Adjust fonts and spacing
- Modify animations and transitions

### Functionality
Extend `js/script.js` to:
- Add new animations
- Implement additional features
- Customize form handling

## 📧 Contact Form

The contact form uses a `mailto:` link to open the user's default email client with pre-filled information. For production use, consider:
- Backend integration with PHP/Node.js
- Form submission services (Formspree, Netlify Forms)
- Database storage
